# @mission-platform/storybook-framework

정식 영어 원문을 기계 지원으로 번역한 문서입니다. 필요 시 사람이 검수하세요. 패키지 이름, 명령, 경로, 기술 식별자는 그대로 둡니다.

> configs/storybook-framework/docs/index.md: [configs/storybook-framework/docs/index.md](../../index.md)
> 언어: 한국어 (ko)

Mission Platform을 위한 환경 선택 Storybook 프레임워크 사전 설정.

## 설치 및 사용

Storybook 작업 공간에 패키지를 추가하고 다음에서 참조합니다.
`.storybook/main.ts` 또는 해당 Storybook 구성. 선택
작업공간의 지원 조건을 통한 프레임워크 하드코딩하지 마세요
공유 구성 요소 패키지의 프레임워크 어댑터.

## 기여하다

달리다 `pnpm --filter @mission-platform/storybook-framework lint` 그리고
스토리북 빌드 검사. 이 패키지를 프레임워크 선택에 집중하고
공유 Storybook 기본값; 구성 요소 스토리가 속해 있습니다. `apps/storybook`.
