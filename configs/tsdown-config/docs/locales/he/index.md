# @mission-platform/tsdown-config

תרגום בסיוע מכונה מהמקור האנגלי הקנוני. יש לבדוק ידנית בעת הצורך. שמות חבילות, פקודות, נתיבים ומזהים טכניים נשארים ללא שינוי.

> configs/tsdown-config/docs/index.md: [configs/tsdown-config/docs/index.md](../../index.md)
> שפה: עברית (he)

עוזרים משותפים לבניית ספריית tsdown עבור סביבות עבודה הניתנות לפרסום.

## התקן והשתמש

```bash
pnpm add --save-dev @mission-platform/tsdown-config
```

השתמש בחבילה מסביבת עבודה `tsdown.config.ts` ולשמור על נקודות כניסה,
תלות חיצונית, ואילוצי פלט מקומיים לחבילה הנבנית.
הצהרות וחבילות שנוצרו שייכים לחבילה זו `dist/` מַדרִיך.

## לִתְרוֹם

לָרוּץ `pnpm --filter @mission-platform/tsdown-config lint` ובדיקת הפורמט שלו.
שמור על פלט דטרמיניסטי ואל תוסיף ענפי יעד ספציפיים למסגרת
לעוזרת הבנייה הנייטרלית.
