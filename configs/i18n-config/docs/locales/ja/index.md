# @mission-platform/i18n-config

正規の英語ソースからの機械支援翻訳です。必要に応じて人手で確認してください。パッケージ名、コマンド、パス、技術識別子は変更しません。

> configs/i18n-config/docs/index.md: [configs/i18n-config/docs/index.md](../../index.md)
> 言語: 日本語 (ja)

Mission Platform ワークスペースの共有ロケールと抽出構成。

## インストールして使用する

i18next を構成するときに、このパッケージを開発依存関係として追加するか、
翻訳抽出:

```bash
pnpm add --save-dev @mission-platform/i18n-config
```

ロケール ソ​​ースを、それを所有するワークスペースの横に置いてください。抽出書き込み
所有するワークスペースの下にあるネームスペース バンドル `locales/<locale>/` ディレクトリ;
リポジトリ レベルのコマンドは、構成されているすべてのワークスペースを調整します。

## 貢献する

公開する前に、パッケージの lint チェックと形式チェックを実行します。パッケージや物を置かないでください。
この構成パッケージ内のアプリケーション翻訳コンテンツ。
