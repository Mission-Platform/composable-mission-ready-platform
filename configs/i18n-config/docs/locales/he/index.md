# @mission-platform/i18n-config

תרגום בסיוע מכונה מהמקור האנגלי הקנוני. יש לבדוק ידנית בעת הצורך. שמות חבילות, פקודות, נתיבים ומזהים טכניים נשארים ללא שינוי.

> configs/i18n-config/docs/index.md: [configs/i18n-config/docs/index.md](../../index.md)
> שפה: עברית (he)

מיקום משותף ותצורת חילוץ עבור סביבות עבודה של Mission Platform.

## התקן והשתמש

הוסף חבילה זו כתלות בפיתוח בעת הגדרת i18next or
מיצוי תרגום:

```bash
pnpm add --save-dev @mission-platform/i18n-config
```

שמור מקורות מקומיים לצד סביבת העבודה שבבעלותם. מיצוי כותב
חבילות מרחבי שמות מתחת למרחב העבודה שבבעלותם `locales/<locale>/` מַדרִיך;
הפקודה ברמת המאגר מתזמרת את כל סביבות העבודה המוגדרות.

## לִתְרוֹם

הפעל את בדיקות מוך החבילה והפורמט לפני הפרסום. אין לשים חבילה או
תוכן תרגום יישומים בחבילת תצורה זו.
