# @mission-platform/i18n-config

ترجمة آلية مساعدة من المصدر الإنجليزي الأساسي. تُراجع يدويًا عند الحاجة. تبقى أسماء الحزم والأوامر والمسارات والمعرّفات التقنية دون تغيير.

> configs/i18n-config/docs/index.md: [configs/i18n-config/docs/index.md](../../index.md)
> اللغة: العربية (ar)

الإعدادات المحلية المشتركة وتكوين الاستخراج لمساحات عمل Mission Platform.

## التثبيت والاستخدام

أضف هذه الحزمة باعتبارها تبعية تطوير عند تكوين i18next أو
استخراج الترجمة:

```bash
pnpm add --save-dev @mission-platform/i18n-config
```

احتفظ بالمصادر المحلية بجانب مساحة العمل التي تمتلكها. يكتب استخراج
حزم مساحة الاسم ضمن مساحة العمل المالكة `locales/<locale>/` دليل؛
يقوم الأمر على مستوى المستودع بتنسيق جميع مساحات العمل التي تم تكوينها.

## يساهم

قم بتشغيل فحص الحزمة والتنسيق قبل النشر. لا تضع الحزمة أو
محتوى ترجمة التطبيق في حزمة التكوين هذه.
