# @mission-platform/i18n-config

정식 영어 원문을 기계 지원으로 번역한 문서입니다. 필요 시 사람이 검수하세요. 패키지 이름, 명령, 경로, 기술 식별자는 그대로 둡니다.

> configs/i18n-config/docs/index.md: [configs/i18n-config/docs/index.md](../../index.md)
> 언어: 한국어 (ko)

Mission Platform 작업 공간에 대한 공유 로케일 및 추출 구성입니다.

## 설치 및 사용

i18next를 구성할 때 이 패키지를 개발 종속성으로 추가하거나
번역 추출:

```bash
pnpm add --save-dev @mission-platform/i18n-config
```

로케일 소스를 소유한 작업공간 옆에 보관하세요. 추출 쓰기
소유 작업공간 아래의 네임스페이스 번들 `locales/<locale>/` 예배 규칙서;
저장소 수준 명령은 구성된 모든 작업 영역을 조정합니다.

## 기여하다

게시하기 전에 패키지 린트 및 형식 검사를 실행하세요. 패키지를 넣지 마십시오.
