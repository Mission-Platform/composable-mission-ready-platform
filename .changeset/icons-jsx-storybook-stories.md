add per-icon Storybook stories for every icon

Each icon now has a co-located `*.vue.stories.tsx` (consumed by the Vue
Storybook) and a matching `*.react.stories.tsx` in the React Storybook app,
catalogued in a dedicated top-level `JSX Icons` section grouped by category
(titles `JSX Icons/<Category>/<Name>`, mirroring the `Icons/<Category>`
groupings of `@mission-platform/icons`), plus a `JSX Icons/Overview` gallery in
both. The story pair is generated by the new `scripts/generate-stories.js`
(`pnpm stories:generate`), and `@storybook/vue3-vite` + `storybook` were added
as devDependencies to support the co-located Vue stories.
