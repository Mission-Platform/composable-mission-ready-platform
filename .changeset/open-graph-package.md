add new `@mission-platform/open-graph` package for generating and dynamically managing Open Graph (and Twitter Card) `<meta>` tags from Vue 3 components. Exposes a `useOpenGraph` composable that reactively syncs metadata into `document.head`, plus pure helpers (`buildMetaTags`, `applyMetaTags`, `clearMetaTags`) for imperative use.
