# שיטות עבודה מומלצות במסגרת

תרגום בסיוע מכונה מהמקור האנגלי הקנוני. יש לבדוק ידנית בעת הצורך. שמות חבילות, פקודות, נתיבים ומזהים טכניים נשארים ללא שינוי.

> docs/framework-best-practices.md: [docs/framework-best-practices.md](../../framework-best-practices.md)
> שפה: עברית (he)

מסמך זה מספק הנחיות לגבי דפוסים אידיומטיים, מודלים של תגובתיות ואופטימיזציות של ביצועים עבור המסגרות הנתמכות על ידי פלטפורמת המשימה. הוא משמש כ**הסבר** לאסטרטגיית ריבוי המסגרות שלנו והתייחסות לפיתוח ספציפי למסגרת.

## אסטרטגיה מרובת מסגרות

פילוסופיית הליבה של פלטפורמת המשימה היא לבנות פעם אחת ולעבד בכל מקום. זה מושג באמצעות **@mission-platform/forge**, המסגרת הראשית של הפלטפורמה: זמן ריצה JSX ניטרלי במסגרתו כל הרכיבים המשותפים (הכל מלבד האפליקציות) וממנו הם מעובדים בצורה חלקה ב-Vue 3, React, ובסביבות נתמכות אחרות.

### דיאלקט הפורג'
בעת בניית חבילות משותפות, מחבר רכיבים באמצעות הפרימיטיבים הנייטרליים של Forge:
- **JSX Factory**: השתמש ב-`h` וב-`Fragment` מ-`@mission-platform/forge`.
- **ווים ניטרליים**: השתמש ב-`useState`, `useRef`, `useEffect`, `useMemo`, `useCallback` ו-`useId`.
- **פרימיטיבים**: השתמש ב-`Slot`, `Teleport`, `Transition` ו-`Dynamic` עבור מבני UI מורכבים.

## Vue 3

Vue 3 היא המסגרת שאיתה בנויים היישומים ב-`apps/`, ויעד העיבוד המקורי העיקרי עבור רכיבי Forge. הרכיבים המשותפים עצמם נכתבו ב-Forge JSX ולא ישירות ב-Vue.

### דפוסים אידיומטיים
- **Composition API**: השתמש ב-`<script setup lang="ts">` עבור כל הרכיבים החדשים.
- **שילוב Forge**: עטפו רכיבים ניטרליים באמצעות `toVueComponent` מ-`@mission-platform/forge/vue`.
- **Composables**: חלץ היגיון מצבי לפונקציות `useXxx` כדי לקדם שימוש חוזר.

### אופטימיזציות של ביצועים
- **תגובתיות רדודה**: השתמש ב-`shallowRef` או `shallowReactive` עבור מערכי נתונים גדולים ומורכבים כדי להימנע מתקורה של פרוקסי.
- **v-memo**: השתמש ב-`v-memo` בתבניות כדי לדלג על עדכוני תת-עץ יקרים בהתבסס על שינויים בתלות.
- **markRaw**: עטוף מופעי ספרייה של צד שלישי (לדוגמה, Chart.js, Mapbox) ב-`markRaw` כדי למנוע מ-Vue לנסות להפוך אותם לתגובתי.

## React

React נתמך באמצעות מתאם זמן הריצה Forge, בעיקר עבור אינטגרציות חיצוניות וכלים פנימיים ספציפיים.

### דפוסים אידיומטיים
- **רכיבים פונקציונליים**: השתמשו ברכיבים פונקציונליים עם ווים.
- **שילוב Forge**: עטפו רכיבים ניטרליים באמצעות `toReactComponent` מ-`@mission-platform/forge/react`.
- **משמעת הוקס**: עקבו בקפדנות אחר "כללי הוקס" כדי להבטיח התנהגות צפויה.

### אופטימיזציות של ביצועים
- **שינון**: השתמש ב-`React.memo`, `useMemo` ו-`useCallback` כדי לשמור על זהות התייחסותית ולהימנע מעיבודים חוזרים מיותרים.
- **תכונות במקביל**: נצל את `useTransition` או `useDeferredValue` לעדכוני ממשק משתמש לא דחופים כדי לשמור על התגובות של השרשור הראשי.

## מסגרות אחרות

Mission Platform מספקת רמות שונות של תמיכה עבור מסגרות אחרות באמצעות מתאמי Forge:

- **SolidJS**: משתמש בתגובתיות עדינה באמצעות אותות. הימנע מהרס של אביזרים כדי לשמור על תגובתיות.
- **Svelte 5**: ממנף רונים (`$state`, `$derived`, `$effect`) לתגובתיות מודרנית.
- **רכיבי אינטרנט (Lit)**: שימושי לבניית רכיבים ניידים במיוחד שצריכים לפעול בסביבות מדור קודם או ללא מסגרת.

## מודלים של ביצועים ותגובתיות

| מסגרת | מודל תגובתיות | אסטרטגיית עדכון |
| :--- | :--- | :--- |
| **Vue 3** | מבוסס פרוקסי | DOM וירטואלי עם אופטימיזציות מהדר. |
| **React** | מצב בלתי משתנה | התאמה וירטואלית של DOM. |
| **SolidJS** | איתותים עדינים | עדכוני DOM ישירים (ללא VDOM). |
| **Svelte 5** | רונים / אותות | עדכוני DOM ישירים באמצעות מהדר. |
| **מואר** | מאפיינים ריאקטיביים | עדכוני Shadow DOM אסינכרוניים. |
