# دليل واجهة برمجة التطبيقات للحزمة

ترجمة آلية مساعدة من المصدر الإنجليزي الأساسي. تُراجع يدويًا عند الحاجة. تبقى أسماء الحزم والأوامر والمسارات والمعرّفات التقنية دون تغيير.

> docs/api-reference.md: [docs/api-reference.md](../../api-reference.md)
> اللغة: العربية (ar)

هذه الصفحة على مستوى المشروع عبارة عن دليل لإمكانيات الحزمة وتوافقها
العقود. التثبيت الأساسي والاستخدام والقيود وتفاصيل واجهة برمجة التطبيقات لـ
كل حزمة تعيش بجانب تلك الحزمة تحتها `packages/*/docs/`, `configs/*/docs/`،
و `forge-plugins/*/docs/`. يجب إضافة مراجع API المُنشأة إلى المالك
الحزمة بدلا من هذه الصفحة.

> **الواردات دائمًا عارية.** شحن الإطار `@mission-platform/*` حزم تعرض واحدة `.`
> دخول يحرسه `mp:vue`, `mp:react`, `mp:solid`، و `mp:web-component` تصدير
> الشروط. حدد الإطار **مرة واحدة** — عبر `resolve.conditions` (يرى `defineFrameworkAppConfig` /
> `frameworkResolveConditions` من `@mission-platform/vite-config`) و `customConditions` (عبر
> `@mission-platform/typescript-config/framework-<name>` الإعدادات المسبقة) - ثم قم باستيراد كل شيء بالعارية
> محدد الحزمة. يرى [إعداد المستهلك الخارجي](external-consumer-setup.md).

## الإطار الأساسي

### @mission-platform/forge

أساس بنية "الكتابة مرة واحدة"، مما يوفر وقت تشغيل JSX وخطافات محايدة لإطار العمل.

| تصدير | اكتب | الوصف |
|:-------------------|:---------|:----------------------------------------------------------------------------------------|
| `h`, `Fragment`    | وظيفة | مصنع JSX وجزء لمكونات التأليف.                                      |
| `useState`         | هوك | ربط حالة محايدة للإطار.                                                           |
| `useEffect`        | هوك | خطاف ذو تأثير محايد للإطار.                                                          |
| `useMemo`          | هوك | خطاف تحفيظ محايد للإطار.                                                     |
| `useRef`           | هوك | خطاف مرجعي محايد للإطار.                                                       |
| `useContext`       | هوك | ربط سياق محايد للإطار.                                                         |
| `toVueComponent`   | محول | تحويل مكون صياغة إلى Vue 3 مكون (من `@mission-platform/forge/vue`).   |
| `toReactComponent` | محول | تحويل مكون صياغة إلى React مكون (من `@mission-platform/forge/react`). |

### @mission-platform/vite-plugin-forge

يقبل برنامج التشغيل المترجم الصريح `FrameworkOutputPlugin` الحالات؛ إنه كذلك
لا توفر التسجيل الإطار. `defineViteForgeComponents` و
`defineTsdownForgeComponents` (بالإضافة إلى الخطاف ومساعدي CMS) يتشاركون في العملية
`ForgeCompilerService` لجلسة بناء أو مشاهدة واحدة.

| القدرة | الوصف |
|:-----------|:------------|
| دورة حياة الخدمة | إعادة استخدام المصدر، والرسم البياني، والمصدر المحلل، والأشعة تحت الحمراء الدلالية، وحالة المنتج المستهدف عبر الإصدارات؛ تخلص من خدمات اللقطة الواحدة بعد الانتهاء وخدمات المراقبة عند الإغلاق. |
| مفاتيح ذاكرة التخزين المؤقت | بصمات المصدر/التبعية/التكوين، وخيارات المترجم وجهاز التوجيه، `tsconfig` `baseUrl`/`paths`ومعرف الهدف وهوية/إصدار البرنامج المساعد والشروط ذات الصلة. |
| شاهد الإبطال | تؤدي الملفات التي تم تغييرها إلى إبطال تبعيات الرسم البياني العكسي، بما في ذلك المكونات المتعدية وإدخالات الخطاف؛ تظل اللقطات المستهدفة غير ذات الصلة قابلة لإعادة الاستخدام. |
| التشخيص/التقرير | تقارير توقيت المرحلة، وعدد مرات الوصول/الإخفاق في ذاكرة التخزين المؤقت، والملفات المتأثرة، والتحذيرات، والأخطاء، وأعداد القطع الأثرية المنبعثة. أخطاء تمنع الترويج. |
| بيان قطعة أثرية | يسرد الإدخالات والوحدات النمطية والإعلانات وخرائط المصدر والأصول والمجاميع الاختبارية ذات النطاق المستهدف قبل الترويج الذري. |
| نقطة التمديد | تنفيذ وتمرير أ `FrameworkOutputPlugin` من المتصل مملوك `forge-plugin-*` طَرد؛ لا تقم بإضافة الفروع المستهدفة إلى برنامج التشغيل المحايد. |

تكوين الأسماء المستعارة من خلال المشروع `tsconfig.json` (`baseUrl` و
`paths`); Vite ويستخدم إعداد الرسم البياني tsdown نفس الحقائق المستعارة. جهاز التوجيه
يتم إعادة توجيه التحديد والمكونات الإضافية لجهاز التوجيه والشروط من خلال المكون و
مساعدين هوك. قد يجلس العامل/الشيطان المستقبلي خلف عقد الخدمة، ولكن
التنفيذ المدعوم قيد التنفيذ حاليًا.

### @mission-platform/router

عقود المسار المحايدة للإطار، والمساعدين المطابقين تمامًا، وعلامات المترجم لـ
الحزم المشتركة. تمتلك التطبيقات سجلات المسار ومثيلات جهاز التوجيه الأصلي؛ ال
يوفر هدف صياغة جهاز التوجيه الذي تم تحديده بواسطة التطبيق إمكانيات وقت التشغيل.

| تصدير/حزمة | اكتب | الوصف |
|:-----------------|:-----|:------------|
| `MpRoute`, `MpRouteLocationRaw`, `MpResolvedLocation` | أنواع | سجلات المسار، والمعلمات، وحالة الاستعلام/التجزئة، والبيانات التعريفية، وأهداف التنقل. |
| `defineRoutes`, `matchRoutes`, `resolveLocation` | الوظائف | تحديد أشجار المسار وحل المسارات بدون DOM أو وقت تشغيل الإطار. |
| `MpNavigationResult`, `MpRouteGuard`, `MpHistory`, `MpRouterAdapter` | أنواع | نتائج/أحداث التنقل والحراس والتاريخ القابل للتوصيل وعقود المحول. |
| `MpLink`, `useMpRoute`, `useMpRouter`, `useMpNavigation`, `MpRouterView` | علامات المترجم | الارتباط المحايد وحالة المسار والملاحة والدقة وقدرات المنفذ التي تستهلكها الحزم المشتركة. |
| `@mission-platform/forge-router-*` | صياغة الأهداف | أهداف جهاز التوجيه الأصلي المحددة بشكل مستقل لـ Vue راوتر, React جهاز التوجيه، وجهاز التوجيه SolidJS، وSvelteKit، وRedwoodSDK، ومكونات الويب. |

تمتلك حزم وقت التشغيل سجلًا وحالة تفاعلية؛ لا تستورد الحزمة المحايدة إطار عمل واجهة المستخدم أبدًا. بالنسبة لمكونات الويب،
قم بتسجيل العناصر مرة واحدة وتمرير الأهداف المعقدة من خلال خصائص DOM بدلاً من السمات المتسلسلة:

```ts
import {
  MpMemoryHistory,
  createWebComponentsRouter,
  registerRouterElements,
  setForgeRouter,
} from '@mission-platform/forge-router-web-components/runtime';

registerRouterElements();
const router = createWebComponentsRouter({
  history: new MpMemoryHistory('/overview'),
  routes: [{ path: '/overview', component: () => 'Documentation' }],
});
setForgeRouter(router);
const link = document.createElement('forge-router-link');
link.to = { path: '/overview', query: { q: 'router' }, hash: 'results' };
link.router = router;
```

## واجهة المستخدم والتصميم

### @mission-platform/tokens

رموز التصميم المركزية للألوان والطباعة والمسافات.

| تصدير | الوصف |
|:--------------|:--------------------------------------------------------------------------|
| `tokens`      | كائن JS/TS يحتوي على جميع رموز التصميم (على سبيل المثال، `tokens.color.primary`). |
| `tokens.scss` | متغيرات SCSS للاستخدام في أوراق الأنماط.                                    |

### @mission-platform/breakpoints

المرافق سريعة الاستجابة ومكونات الرؤية.

| تصدير | اكتب | الوصف |
|:-----------------|:----------|:-----------------------------------------------------------|
| `useBreakpoints` | هوك | إرجاع حالة نقطة التوقف التفاعلية.                        |
| `ShowIf`         | مكون | يتم عرض الأطفال فقط عند تطابق شرط نقطة التوقف. |
| `HideIf`         | مكون | إخفاء الأطفال عند تطابق شرط نقطة التوقف.        |

### @mission-platform/components

تم تأليف مكونات واجهة المستخدم المشتركة مرة واحدة وهي متاحة لأطر عمل متعددة.

- **استيراد**: دائمًا `@mission-platform/components`; النشط `mp:<framework>` الحالة تقرر ما إذا كنت ستحصل على
  Vue 3, React, Solidأو بناء مكون الويب.
- **المسارات الفرعية لكل مكون**: `@mission-platform/components/<path>` (e.g.
  `@mission-platform/components/atoms/forge-badge/forge-badge`) يدرك الحالة أيضًا، ويقوم بتحميل ذلك المكون فقط
  قطعة.
- **عناصر**: `ForgeButton`, `ForgeInput`, `ForgeModal`وأكثر من ذلك.

### صياغة أهداف المترجم

هؤلاء يعيشون في `forge-plugins/` بدلا من `packages/`. يقرر البرنامج الإضافي **framework** وقت التشغيل الذي يعتبر مكونًا محايدًا
تم تخفيضه إلى؛ يحدد هدف **CMS** نظام المحتوى الأساسي الذي سيتم عرضه عليه. يتكون المحوران، لذلك أي CMS
قد يكون الهدف مرتبطًا بأي مكون إضافي لإطار العمل. انظر [صياغة خط أنابيب مترجم](../../../vite-plugins/forge/docs/locales/ar/reference/compiler.md).

| الحزمة | الغرض |
|:-------------------------------------------------|:--------------------------------------------------------------------------------|
| `@mission-platform/forge-plugin-api`             | `FrameworkOutputPlugin` العقد وأنواع IR الدلالية وأنواع محولات البناء.   |
| `@mission-platform/forge-plugin-react`           | React هدف الإخراج.                                                            |
| `@mission-platform/forge-plugin-vue`             | Vue 3 هدف الإخراج                                                            |
| `@mission-platform/forge-plugin-solid`           | Solid هدف الإخراج.                                                            |
| `@mission-platform/forge-plugin-svelte`          | Svelte 5 هدف الإخراج                                                         |
| `@mission-platform/forge-plugin-web-components`  | هدف إخراج مكونات الويب.                                                   |
| `@mission-platform/forge-cms-plugin-api`         | `CmsOutputPlugin` العقد ونموذج المحتوى المحايد وبرنامج تشغيل CMS وبناء المساعدين. |
| `@mission-platform/forge-cms-storyblok`          | كائنات مكون Storyblok وأغلفة الكتلة و `components.json`.              |
| `@mission-platform/forge-cms-astro`              | ثابت `.astro` قوالب و `client:load` جزر الإطار.                  |
| `@mission-platform/forge-cms-ghost`              | أجزاء شبح المقاود و `config.custom` جزء الموضوع.                 |
| `@mission-platform/forge-cms-jekyll`             | جيكل السائل يشمل، `_data` مخطط، و `_config.yml` جزء.           |
| `@mission-platform/forge-cms-webflow`            | تدفق الويب `declareComponent` مكونات الكود و `webflow.json` جزء المكتبة. |
