# البرامج النصية المساعدة المشتركة

ترجمة آلية مساعدة من المصدر الإنجليزي الأساسي. تُراجع يدويًا عند الحاجة. تبقى أسماء الحزم والأوامر والمسارات والمعرّفات التقنية دون تغيير.

> docs/configs/scripts-config.md: [docs/configs/scripts-config.md](../../../configs/scripts-config.md)
> اللغة: العربية (ar)

يظل هذا الدليل عمدًا في طبقة وثائق المشروع: `scripts/`
عبارة عن حزمة مساحة عمل خاصة تحتوي على تنسيق المستودع بدلاً من
مكتبة قابلة للنشر.
تظل الأوامر الخاصة بالحزمة والتطبيق موثقة بجانب ملفاتها
امتلاك مساحة العمل.

تحتفظ Mission Platform بمجموعة من البرامج النصية للأدوات المساعدة المشتركة في الجذر
الدليل `scripts/`. يتم تسجيل البرامج النصية لحزمتها كمهام Turbo، بينما
يعرض الجذر `package.json` أغلفة الراحة التي تفوض Turbo.

## ملخص

تعمل هذه البرامج النصية على أتمتة مهام monorepo الشائعة، مثل إعداد التطوير المحلي والتحقق من البناء. الترجمة
يتم تعريف الاستخراج بواسطة كل تطبيق أو حزمة ويتم تنسيقه من جذر المستودع باستخدام Turborepo.

## البرامج النصية المتاحة

### عائلات المهام Turbo

استخدم أغلفة الجذر لأدوات المستودع المساعدة أدناه. كل أمر هو
مهمة منفصلة، بحيث يمكن لـ Turbo تجزئتها وجدولتها بشكل مستقل:

| الأمر | الغرض | سياسة التخزين المؤقت |
| :----------------------------------- | :---------------------------------------------------------------- | :---------------------------------------------------------- |
| `pnpm validate` | قم بتشغيل التحقق الثابت لخاصية المكون المستقل من خلال Turbo. | يتم تخزين المهمة مؤقتًا بشكل مستقل.                           |
| `pnpm docs:generate` | إنشاء وثائق مرجعية للحزمة والامتداد.           | يتم تخزين الملفات المرجعية التي تم إنشاؤها مؤقتًا.                       |
| `pnpm validate:exports` | التحقق من خرائط تصدير الحزمة والأهداف المبنية.                     | قابلة للتخزين المؤقت عندما لا تتغير مدخلاتها.                    |
| `pnpm validate:component-properties` | تحقق من إعلانات خصائص المكونات مقابل أنماط المصدر.      | قابلة للتخزين المؤقت وخالية من الإخراج.                                  |
| `pnpm validate:inventory` | إنتاج مخزون التحقق من صحة وقت التشغيل.                         | العناصر القابلة للتخزين المؤقت تحت `.artifacts/runtime-validation/`. |
| `pnpm validate:framework` | التحقق من صحة تغطية وقت تشغيل الإطار.                              | القطع الأثرية القابلة للتخزين المؤقت ضمن `.artifacts/runtime-validation/`. |
| `pnpm validate:app` | التحقق من صحة تغطية وقت تشغيل التطبيق.                            | القطع الأثرية القابلة للتخزين المؤقت ضمن `.artifacts/runtime-validation/`. |
| `pnpm validate:target` | التحقق من صحة أهداف Storybook التي تم تكوينها.                            | القطع الأثرية القابلة للتخزين المؤقت تحت `.artifacts/runtime-validation/`. |
| `pnpm validate:runtime` | قم بتشغيل مجموعة التحقق من صحة وقت التشغيل الكامل.                            | لم يتم تخزينه مؤقتًا لأنه يبدأ عمليات التشغيل الخارجية.    |
| `pnpm visual:parity` | قارن مخرجات Storybook المقدمة عبر الأطر.              | لم يتم تخزينه مؤقتًا لأنه يبدأ تشغيل خوادم التطوير.           |
| `pnpm test:runtime-validation` | قم بإجراء اختبارات وحدة التحقق من صحة وقت التشغيل المركزة.                    | يمكن تخزينها مؤقتًا وفقًا لمدخلات مهمة الاختبار.                |

### استخراج i18n (`i18n:extract`)

يوفر كل تطبيق أو حزمة تمتلك ترجمات برنامجًا نصيًا `i18n:extract` و`i18next.config.ts`. يكتب الأمر
حزم مساحة الاسم ضمن دليل `locales/<locale>/` لكل مساحة عمل. قم بتشغيل الاستخراج لجميع مساحات العمل التي تم تكوينها من
جذر المستودع:

```bash
pnpm i18n:extract
```

### إنشاء شهادة المطورين (`generate-dev-cert.ts`)

يُنشئ شهادات SSL/TLS محلية لتطوير HTTPS. وهذا مفيد لاختبار الميزات التي تتطلب تأمينًا
السياق (على سبيل المثال، الوصول إلى الكاميرا عبر `@mission-platform/code-scanner`).

```bash
pnpm exec tsx scripts/generate-dev-cert.ts
```

### التحقق من دقة الإطار (`verify-framework-resolution.mjs`)

التحقق من أن حزمة صادرات `@mission-platform/*` تتوافق بشكل صحيح مع بنية إطار العمل المقصود (Vue، React، وما إلى ذلك)
بناء على ظروف التصدير البيئية.

```bash
node scripts/verify-framework-resolution.mjs
```

### إنشاء الوثائق (`docs:generate`)

يعد إنشاء الوثائق مهمة Turbo مملوكة لشركة `@mission-platform/scripts`.
يعتمد تطبيق المستندات على تلك المهمة بشكل صريح، لذلك التطوير والبناء
لا تبدأ الأوامر في إنشاء Turbo المتداخل.

## طرق التنفيذ

### عبر مدير الحزم

المرافق المستخدمة بشكل متكرر متاحة كما Turbo- المدعومة `pnpm` البرامج النصية في
root `package.json`:

```bash
pnpm run <script-name>
```

بالنسبة للاستدعاء على نطاق الحزمة، استخدم Turbo مباشرة:

```bash
pnpm exec turbo run validate:exports --filter=@mission-platform/scripts
```

### التنفيذ المباشر

يمكن تشغيل البرامج النصية الفردية TypeScript باستخدام `tsx` أو `node --experimental-strip-types`:

```bash
pnpm exec tsx scripts/<filename>.ts
```

## إرشادات المساهمة

عند إضافة برنامج نصي مشترك جديد:

- ضعه في الدليل `scripts/`.
- استخدم TypeScript حيثما أمكن ذلك.
- إذا كان البرنامج النصي يعتمد على حزم خارجية، فقم بإضافتها إلى `package.json` الخاص بمساحة العمل المالكة.
- توثيق غرض البرنامج النصي واستخدامه في هذا الملف.
- قم بإضافة إدخال مناظر في الجذر `package.json` إذا كانت أداة مساعدة تستخدم بشكل متكرر.
