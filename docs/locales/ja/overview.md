Mission Platform は、構築用に設計された、構成可能でパッケージ駆動型のフレームワークに依存しないコンポーネント プラットフォームです。
再利用可能な構成要素を備えた実稼働対応アプリケーション。最新のモノリポジトリ アーキテクチャを活用して、
複雑なマルチアプリケーションエコシステムのための非常に効率的な開発環境。

## 主な特長

|特集 |説明 |
|:----------------------|:---------------------------------------------------------------------------------------------------------------------------------------|
| **JSX ランタイムを鍛造** |フレームワークに依存しない JSX 方言: 一度作成すれば、ランタイム オーバーヘッドなしで Vue 3、React、Svelte、Solid、および Web コンポーネントをビルドできます。 |
| **コンポーネント ライブラリ** |複数のフレームワークに対して一度作成される、レイアウト、タイポグラフィ、およびインタラクティブなコンポーネントの包括的なセット。                           |
| **デザイントークン** |一貫したテーマのために SCSS および TypeScript アーティファクトを生成する DTCG 準拠のトークン システム。                                     |
| **アグノスティック ルーティング** | UI フレームワークから独立して動作するタイプセーフなルーティング システム。                                                               |
| **ユニバーサル I18n** |専用の Vue および React アダプターを備えた、i18next に基づくフレームワークに依存しない国際化ラッパー。                              |
| **Wasm ユーティリティ** | WebAssembly を利用したバーコード スキャン、スペル チェックなどの高パフォーマンス ユーティリティ。                                     |

## テクノロジースタック

Mission Platform は、最新の高性能スタック上に構築されています。

- **Forge JSX (`@mission-platform/forge`)**: 主要な UI フレームワーク — フレームワークに依存しない JSX ランタイム。
  共有コンポーネント (アプリを除くすべて) が作成されます。
- **Vue 3**: `apps/` のアプリケーションが構築されるフレームワーク、およびいくつかのネイティブ レンダー ターゲットの 1 つ
  コンポーネントを鍛造します。
- **TypeScript**: すべてのソース コードの標準。
- **Vite**: 高速 HMR と最適化されたプロダクション バンドルを強化するビルド ツール。
- **pnpm ワークスペース**: 共有ロックファイルによる効率的な依存関係管理。
- **Turborepo**: 高パフォーマンスのタスク オーケストレーションとキャッシュ。
- **Cloudflare ワーカー/ページ**: アプリケーションと API の主要なデプロイメント ターゲット。
- **ストーリーブック**: コンポーネント開発およびビジュアル テスト用のワークベンチ。

## 生態系の構造

リポジトリは、いくつかの異なる領域に編成されています。

- **`apps/`**: パッケージを製品に組み込む展開可能なアプリケーション (`my-care-notes`、`website` など)。
- **`packages/`**: `@mission-platform/components`、`@mission-platform/router`、および `@mission-platform/router` を含むコア構成要素
  `@mission-platform/i18n`。
- **`packages/tooling/configs/`**: ESLint、Prettier、TypeScript、および Vite の共有構成。
- **`packages/tooling/vite/`**: デザイン トークン、Forge コンパイル、SEO 用のカスタム ビルド時ツール。
- **`packages/edge/workers/`**: バックエンド ロジックと SPA サービス機能を提供する Cloudflare ワーカー。
