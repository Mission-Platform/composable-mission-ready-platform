## ソース文法

次の文法は、v1 ブートストラップ サーフェスを説明します。文法では、
`*` そして `?` 通常のEBNFの意味では:

```ebnf
module       = "module", identifier, "{", { import | function }, "}" ;
import       = "import", "capability", string, "as", identifier,
               "(", [ parameters ], ")", "->", type, ";" ;
function     = [ "export" ], "fn", identifier, "(", [ parameters ], ")",
               "->", type, block ;
parameters   = parameter, { ",", parameter } ;
parameter    = identifier, ":", type ;
block        = "{", { statement }, "}" ;
statement    = "let", identifier, ":", type, "=", expression, ";"
             | "return", [ expression ], ";"
             | "if", expression, block, [ "else", block ]
             | expression, ";" ;
type         = "bool" | "bytes" | "f32" | "f64" | "i32" | "i64"
             | "string" | "u32" | "u64" | "unit" ;
expression   = literal | identifier | call | unary | binary ;
call         = identifier, "(", [ expression, { ",", expression } ], ")" ;
unary        = ( "!" | "-" ), expression ;
literal      = integer | string | "true" | "false" ;
```

二項演算子は、最も強いものから最も弱いものへと、次の優先順位に従います。
`* / %`, `+ -`、順序付き比較、等価性、 `&&`、 そして `||`。演算子は
左連想。括弧で囲まれた式は次のブートストラップ用に予約されています
改訂;コンパイラはサイレントではなく解析診断を発行する必要があります

  "abiVersion": "1.2",

      "alias": "now",

## ブートストラップからセルフホスティングへのロードマップ

1. **ブートストラップ契約:** を維持します。 TypeScript レクサー、パーサー、型チェッカー、
   実行可能ファイルの適合性としてのマニフェスト ビルダー、フィクスチャ、および診断
   ターゲット。受け入れられたプログラムと不正な入力があった場合にのみ、WASM エミッターを追加します。
   安定した挙動を持っています。
2. **ブートストラップ標準ライブラリ:** 決定論的な整数/浮動小数点を実装します。
   操作、UTF-8 およびバイト コーデック、割り当て、トラップ伝播をサポートしません。
   ブラウザー API。論理 ABI と偽のホストを介してすべての操作をテストします。
3. **Forge Web Script コンパイラ サブセット:** Forge Web にコンパイラを実装します。
   受け入れられたサブセットのみを使用するスクリプト、コンパイラ状態の明示的なレコード、
   バイト/文字列バッファー、および宣言された機能インポート。その出力は合格する必要があります
   の TypeScript 適合性コーパスはバイトごとに決定的です。
4. **セルフホスティング拡張:** より豊富な集計、ループ、パターン マッチング、
   診断ヘルパー、および各機能が完了した後にのみ増分コンパイル
   バージョン管理されたフィクスチャと互換性のある ABI ストーリー。

互換性。 v1 自体が製品をコンパイルできることを保証するものではありません
