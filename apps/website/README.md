# @mission-platform/website

The main marketing and showcase website for **Mission Platform** — a composable, mission-ready Vue 3 platform.

This app demonstrates what the platform makes possible by composing the shared `packages/` (components, tokens, icons, breakpoints, i18n) into a real, deployable Vue 3 application.

## Scripts

```bash
# Run the dev server
pnpm --filter @mission-platform/website dev

# Build for production
pnpm --filter @mission-platform/website build

# Preview the production build
pnpm --filter @mission-platform/website preview

# Tests / lint / format
pnpm --filter @mission-platform/website test
pnpm --filter @mission-platform/website lint
pnpm --filter @mission-platform/website format
```
