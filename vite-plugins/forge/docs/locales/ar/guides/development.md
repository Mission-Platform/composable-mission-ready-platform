# قم بتطوير البرنامج المساعد Forge Vite

ترجمة آلية مساعدة من المصدر الإنجليزي الأساسي. تُراجع يدويًا عند الحاجة. تبقى أسماء الحزم والأوامر والمسارات والمعرّفات التقنية دون تغيير.

> vite-plugins/forge/docs/guides/development.md: [vite-plugins/forge/docs/guides/development.md](../../../guides/development.md)
> اللغة: العربية (ar)

## التثبيت والتحقق

قم بتشغيل عمليات التحقق المركزة من جذر المستودع:

```bash
pnpm install
pnpm --filter @mission-platform/vite-plugin-forge build:check
pnpm --filter @mission-platform/vite-plugin-forge test
```

البناء باستخدام `pnpm --filter @mission-platform/vite-plugin-forge build`. حزم
ويتم إرسال الإعلانات إلى `dist/`؛ لا تلتزم بمخرجات البناء المحلية.

## تغيير المترجم

حافظ على التحليل والتطبيع والأشعة تحت الحمراء الدلالية والتخزين المؤقت والتشخيصات محايدة.
ينتمي خفض الهدف وتوليد المصدر إلى المجموعة المحددة
حزمة `@mission-platform/forge-plugin-*`. إضافة تغطية الانحدار لذاكرة التخزين المؤقت
الهوية، والإبطال، والتشخيص، والتحف التي تم إنشاؤها، والمكونات الإضافية للمتصل
الحفاظ عند تغيير السائق.

يجب أن تظل الحزمة قابلة للاستخدام من كل من Vite وtsdown. لا تضيف هدفا
تبديل تبعية وقت تشغيل الجدول أو إطار العمل إلى برنامج التشغيل المحايد. تحديث
[مرجع خط أنابيب المترجم](../reference/compiler.md) عندما تكون مرحلة عامة أو
تغييرات العقد قطعة أثرية.
