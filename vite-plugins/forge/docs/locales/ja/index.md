Vite および tsdown 用のフレームワーク中立の Forge コンパイラ ドライバー。このパッケージ
独自の解析、正規化、セマンティック分析、中立的な最適化、キャッシュ、
ターゲットのディスパッチ、および汎用ビルド オーケストレーション。 framework and CMS output
パッケージは、ターゲット固有の引き下げと生成を所有します。
