# @mission-platform/api-proxy

תרגום בסיוע מכונה מהמקור האנגלי הקנוני. יש לבדוק ידנית בעת הצורך. שמות חבילות, פקודות, נתיבים ומזהים טכניים נשארים ללא שינוי.

> workers/api-proxy/docs/index.md: [workers/api-proxy/docs/index.md](../../index.md)
> שפה: עברית (he)

דוגמה ל-Cloudflare Worker שמפעיל מסלולי API מאושרים לקריאה בלבד ל-a
שירות קבוע במעלה הזרם. סביבת העבודה הזו היא הבעלים של מדיניות הבקשות, כותרת
חיטוי, וגבול שגיאה עבור מטפל ה-proxy.

## השתמש בעובד

החבילה מייצאת את המטפל המצורף שלה מ-`@mission-platform/api-proxy`.
בנה אותו לפני הפניה ל-`dist/index.js` מתצורת Wrangler:

```bash
pnpm --filter @mission-platform/api-proxy build
```

רק בקשות `GET` ו-`HEAD` ל-`/users` ו-`/v1` מתקבלות. שאילתה
מחרוזות מועברות; אישורים, ה-`Host` המקורי, והופ-אחר-הופ
הכותרות מוסרות. כשלים במעלה הזרם או בבנייה של בקשה מחזירים `502`.

## מגבלות

לחבילה אין תצורת פריסת Wrangler צ'ק-אין והיא אינה א
פרוקסי הפוך לשימוש כללי. הוסף תצורת פריסה מפורשת ו
סקור שינויים באימות, במעלה הזרם ובמטמון לפני חשיפתם.
