# @mission-platform/api-proxy

ترجمة آلية مساعدة من المصدر الإنجليزي الأساسي. تُراجع يدويًا عند الحاجة. تبقى أسماء الحزم والأوامر والمسارات والمعرّفات التقنية دون تغيير.

> workers/api-proxy/docs/index.md: [workers/api-proxy/docs/index.md](../../index.md)
> اللغة: العربية (ar)

مثال على Cloudflare Worker الذي وافق الوكلاء على مسارات واجهة برمجة التطبيقات للقراءة فقط إلى ملف
خدمة المنبع الثابتة. تمتلك مساحة العمل هذه سياسة الطلب والرأس
التعقيم وحدود الخطأ لمعالج الوكيل.

## استخدم العامل

تقوم الحزمة بتصدير المعالج المجمع الخاص بها من `@mission-platform/api-proxy`.
قم بإنشائه قبل الرجوع إلى `dist/index.js` من تكوين Wrangler:

```bash
pnpm --filter @mission-platform/api-proxy build
```

يتم قبول طلبات `GET` و`HEAD` إلى `/users` و`/v1` فقط. الاستعلام
يتم إعادة توجيه السلاسل؛ بيانات الاعتماد، و`Host` الأصلي، والقفزة تلو الأخرى
تتم إزالة الرؤوس. ترجع حالات فشل المنبع أو طلب الإنشاء `502`.

## القيود

لا تحتوي الحزمة على تكوين نشر Wrangler مسجل وهي ليست ملف
الوكيل العكسي للأغراض العامة. قم بإضافة تكوين نشر صريح و
قم بمراجعة تغييرات المصادقة والمنبع والتخزين المؤقت قبل الكشف عنها.
