# @mission-platform/web-lua

Machineondersteunde vertaling van de canonieke Engelse bron. Handmatig nalezen indien nodig. Pakketnamen, opdrachten, paden en technische identificatoren blijven ongewijzigd.

> packages/web-lua/docs/index.md: [packages/web-lua/docs/index.md](../../index.md)
> Taal: Nederlands (nl)

Lua runtime foundation, eigendom van gasten, samengesteld op basis van Forge Web Script. Dit pakket
is eigenaar van het runtime-compatibiliteitscontract en de grens van de hostmogelijkheden.

## Begin hier

- [Lua 5.5.1 compatibiliteitsreferentie](reference/compatibility.md) — getest,
  capaciteitsafhankelijk en onopgelost gedrag.
- [Bouw- en testhandleiding](guides/development.md) — runtime-armaturen en uitvoer
  beperkingen.
- Het pakket README en de gegenereerde referentie bieden beknopte pakket-API-opmerkingen.

De browserinvoer is `@mission-platform/web-lua`; Node-consumenten gebruiken de
expliciete `@mission-platform/web-lua/node`-export. Hosteffecten worden ontkend door
standaard en vereisen een expliciet mogelijkhedenbeleid.
