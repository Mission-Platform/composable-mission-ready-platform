# WebLua Lua 5.5.1 מטריצת תאימות

תרגום בסיוע מכונה מהמקור האנגלי הקנוני. יש לבדוק ידנית בעת הצורך. שמות חבילות, פקודות, נתיבים ומזהים טכניים נשארים ללא שינוי.

> packages/web-lua/docs/reference/compatibility.md: [packages/web-lua/docs/reference/compatibility.md](../../../reference/compatibility.md)
> שפה: עברית (he)

הדו"ח הזה הוא שמרני בכוונה. `matched` פירושו שההתנהגות מכוסה על ידי מתקן ברמת אורח ויש לו תוצאה צפויה דטרמיניסטית; `capability-gated` פירושו שאפקטים מארח דורשים מדיניות מפורשת; `unresolved` פירושו שההתנהגות נמצאת במעקב, אך אין להתייחס אליה כאל עוברת.
