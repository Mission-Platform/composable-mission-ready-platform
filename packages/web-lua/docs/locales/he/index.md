# @mission-platform/web-lua

תרגום בסיוע מכונה מהמקור האנגלי הקנוני. יש לבדוק ידנית בעת הצורך. שמות חבילות, פקודות, נתיבים ומזהים טכניים נשארים ללא שינוי.

> packages/web-lua/docs/index.md: [packages/web-lua/docs/index.md](../../index.md)
> שפה: עברית (he)

קרן Lua זמן ריצה בבעלות אורחים, מורכבת מ-Forge Web Script. החבילה הזו
הבעלים של חוזה תאימות זמן הריצה וגבול יכולת המארח שלו.

## התחל כאן

- [התייחסות לתאימות Lua 5.5.1](reference/compatibility.md) - נבדק,
  התנהגות תלוית יכולות והתנהגות בלתי פתורה.
- [מדריך בנייה ובדיקה](guides/development.md) - מתקנים ופלט זמן ריצה
  אילוצים.
- החבילה README וההפניה שנוצרה מספקים הערות תמציתית של חבילה API.

ערך הדפדפן הוא `@mission-platform/web-lua`; צרכנים Node משתמשים ב-
ייצוא `@mission-platform/web-lua/node` מפורש. השפעות המארח נדחות על ידי
ברירת מחדל ודורשים מדיניות יכולת מפורשת.
