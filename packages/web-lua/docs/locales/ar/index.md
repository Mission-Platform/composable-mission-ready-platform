# @mission-platform/web-lua

ترجمة آلية مساعدة من المصدر الإنجليزي الأساسي. تُراجع يدويًا عند الحاجة. تبقى أسماء الحزم والأوامر والمسارات والمعرّفات التقنية دون تغيير.

> packages/web-lua/docs/index.md: [packages/web-lua/docs/index.md](../../index.md)
> اللغة: العربية (ar)

تم تجميع مؤسسة Lua وقت التشغيل المملوكة للضيوف من Forge Web Script. هذه الحزمة
يمتلك عقد توافق وقت التشغيل وحدود قدرة المضيف الخاصة به.

## ابدأ هنا

- [مرجع التوافق لوا 5.5.1](reference/compatibility.md) - تم اختباره،
  القدرة على بوابات، والسلوك الذي لم يتم حله.
- [دليل البناء والاختبار](guides/development.md) - تركيبات وقت التشغيل والمخرجات
  القيود.
- توفر الحزمة README والمرجع الذي تم إنشاؤه ملاحظات موجزة عن واجهة برمجة التطبيقات الخاصة بالحزمة.

إدخال المتصفح هو `@mission-platform/web-lua`؛ يستخدم المستهلكون Node
تصدير `@mission-platform/web-lua/node` صريح. تم رفض تأثيرات المضيف بواسطة
الافتراضي ويتطلب سياسة قدرة واضحة.
