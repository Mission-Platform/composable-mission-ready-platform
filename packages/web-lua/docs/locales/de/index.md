# @mission-platform/web-lua

Maschinenunterstützte Übersetzung aus der kanonischen englischen Quelle. Bei Bedarf manuell nachprüfen. Paketnamen, Befehle, Pfade und technische Bezeichner bleiben unverändert.

> packages/web-lua/docs/index.md: [packages/web-lua/docs/index.md](../../index.md)
> Sprache: Deutsch (de)

Gasteigene Lua-Laufzeitgrundlage, kompiliert aus Forge Web Script. Dieses Paket
besitzt den Laufzeitkompatibilitätsvertrag und seine Hostfähigkeitsgrenze.

## Beginnen Sie hier

- [Lua 5.5.1-Kompatibilitätsreferenz](reference/compatibility.md) — getestet,
  fähigkeitsabhängiges und ungelöstes Verhalten.
- [Build- und Testanleitung](guides/development.md) – Laufzeit-Fixtures und -Ausgabe
  Einschränkungen.
  – Die Paket-README-Datei und die generierte Referenz enthalten prägnante Paket-API-Hinweise.

Der Browsereintrag ist `@mission-platform/web-lua`; Node Verbraucher verwenden die
expliziter `@mission-platform/web-lua/node`-Export. Host-Effekte werden abgelehnt von
Standardmäßig und erfordern eine explizite Fähigkeitsrichtlinie.
