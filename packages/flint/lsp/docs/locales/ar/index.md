# @mission-platform/flint-lsp

ترجمة آلية مساعدة من المصدر الإنجليزي الأساسي. تُراجع يدويًا عند الحاجة. تبقى أسماء الحزم والأوامر والمسارات والمعرّفات التقنية دون تغيير.

> packages/flint-lsp/docs/index.md: [packages/flint-lsp/docs/index.md](../../index.md)
> اللغة: العربية (ar)

خادم بروتوكول خادم اللغة stdio لـ Flint v1. الحزمة
يمتلك سلوك النقل ومساحة العمل الذي يواجه المحرر ؛ تبقى دلالات اللغة
مملوكة لـ `@mission-platform/flint`.

## ابدأ هنا

- [مرجع أدوات اللغة](reference/language-service.md) - التشخيص،
  الإكمال والتحويم والرموز الدلالية والحدود المدعومة.
- [دليل البناء والاختبار](guides/development.md) — فحص الخادم المحلي و
  تركيبات البروتوكول.
- [`llms.txt` في حزمة اللغة](../../../../flint/llms.txt) - الأساسية
  ملاحظات واجهة برمجة تطبيقات اللغة.

يتطلب الخادم Node.js `>=24.0.0` ويكشف عن `flint-lsp`
ثنائي مع المسارات الفرعية للوحدة `server` و`workspace`.
