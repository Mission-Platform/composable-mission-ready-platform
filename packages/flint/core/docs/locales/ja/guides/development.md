## パッケージをインストールして確認する

リポジトリ ルートから依存関係をインストールし、パッケージ チェックを実行します。

```bash
pnpm install
pnpm --filter @mission-platform/flint build:check
pnpm --filter @mission-platform/flint test
```

公開する前に `pnpm --filter @mission-platform/flint build` を実行します。
このビルドは、ブラウザーセーフなバンドルと宣言ファイルを `dist/` の下に出力します。
