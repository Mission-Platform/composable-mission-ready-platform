# לפתח את פלינט

תרגום בסיוע מכונה מהמקור האנגלי הקנוני. יש לבדוק ידנית בעת הצורך. שמות חבילות, פקודות, נתיבים ומזהים טכניים נשארים ללא שינוי.

> packages/flint/core/docs/guides/development.md: [packages/flint/core/docs/guides/development.md](../../../guides/development.md)
> שפה: עברית (he)

מדריך זה מיועד לתורמים המשנים את מנתח Flint, מסומן
חוזים, או תווי התאמה.

## התקן ובדוק את החבילה

משורש המאגר, התקן תלות והפעל את בדיקות החבילה:

```bash
pnpm install
pnpm --filter @mission-platform/flint build:check
pnpm --filter @mission-platform/flint test
```

הפעל את `pnpm --filter @mission-platform/flint build` לפני הפרסום.
ה-build פולט את החבילה וההצהרה בטוחה לדפדפן תחת `dist/`.

## הוסף שינוי שפה

עדכן את הדקדוק ואת החזית המסומנת ביחד. הוסף מתקן ממוקד
`src/fixtures/` ומבחן רגרסיה לאבחון או התנהגות שנוצרה.
השאר את גרסת השפה `1.0` וגרסת ABI `1.2` מפורשת אלא אם השינוי הוא
תיקון תאימות מכוון. שינויים ב-ABI חייבים לעדכן מניפסטים,
מעמיסים, ותיעוד התאימות.

החבילה בטוחה לדפדפן. אל תוסיף ממשקי API של Node בלבד לחזית הציבורית;
כלי עבודה ספציפיים ל-Node שייך ל-`@mission-platform/flint-cli`.

## חפצים שנוצרו ומקורם

מקורות `.flint` המוכנסים תחת `src/self-hosted/fws/` הם חפצי מקור,
JavaScript לא מועתק ביד. שמור על פלט שנוצר ב-`dist/` ואל תתחייב
פלט בנייה מקומי. הפניה לתיעוד החבילה נשמרת לצד
החבילה ותיווצר מחדש על ידי זרימת העבודה של חילוץ התיעוד.

## בדיקת צינור דו-שלבי

הגבול הקדמי הקנוני הוא גרף Sea-of-Nodes הדטרמיניסטי. ה
הגרף עובר אופטימיזציה לפני הנמכה ל-Wasm IR, שבו חל מייעל שני
הפצה בטוחה לאחור, הסרת קוד מת, פישוט כתובות, מיתוג
הנמכה, ופריסה דטרמיניסטית. שמור על שני השלבים ניתנים לביקורת: מייעל
יש לשמור את הדוחות ואת מדיניות הגבולות שנבחרה בחפצי מהדר.

השתמש בבדיקות גבולות זמן ריצה אלא אם כלל מייצר הוכחה קובע כל
גישה בטוחה. `proven-safe` ו-`excluded-by-profile` הן מדיניות מפורשת
ערכים, לא התנהגות שחרור מרומזת. חפץ מטמון `.sonir.json` הוא
נתוני אבחון בלבד; על הקוראים לאמת את הסכימה, הגיבובים, המדיניות ו
מגבלות לפני הצגתו, ולעולם אסור להפעיל תוכן גרף.

עבור בדיקות עשן CLI:

```bash
flint check src/example.flint --bounds-checks runtime --optimizer-report --format json
flint inspect-sonir .cache/example.sonir.json --format json
```

בעת שינוי ניתוח, הוסף עובדות ובדיקת אבחון יציבה לפני השינוי
כלל אופטימיזציה. ניתוח פיתוח אמור לחשוף טווחים לא ידועים,
כינוי/מצבי חיים, כיסוי מיתוג והעברת מטא נתונים; ניתוח קפדני חייב
לחסום בקשות לא בטוחות של גבולות-מדיניות והפרות אזור/בעלות.
