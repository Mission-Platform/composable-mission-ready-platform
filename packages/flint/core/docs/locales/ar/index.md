# @mission-platform/flint

ترجمة آلية مساعدة من المصدر الإنجليزي الأساسي. تُراجع يدويًا عند الحاجة. تبقى أسماء الحزم والأوامر والمسارات والمعرّفات التقنية دون تغيير.

> packages/flint/core/docs/index.md: [packages/flint/core/docs/index.md](../../index.md)
> اللغة: العربية (ar)

عقود اللغة Flint v1، ومحلل التمهيد، وتركيبات المطابقة.
تمتلك هذه الحزمة عقد اللغة والوثائق الخاصة بالمستهلكين و
المساهمين.

## ابدأ هنا

- [مرجع اللغة وABI](reference/language.md) - القواعد والأنواع والإمكانيات،
  التشخيص والبيانات وسلوك المترجم.
- [دليل البناء والاختبار](guides/development.md) - الفحوصات والتركيبات المحلية والتي تم إنشاؤها
  التحف.
- [`llms.txt`](../../../llms.txt) - واجهة برمجة تطبيقات موجزة وملاحظات استخدام للأدوات والمساعدين.

تدعم الحزمة مطابقة `Option`/`Result` الخالية من الاستثناءات، وتصدير `iter fn`،
ملفات تعريف الميزات المستهدفة الواضحة، وتصحيح الأخطاء الحتمية المحسنة/غير المحسنة
التحف. إصدار اللغة هو `1.0` وإصدار ABI المنطقي هو `1.2`.
