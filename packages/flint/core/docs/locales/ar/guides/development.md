# تطوير فلينت

ترجمة آلية مساعدة من المصدر الإنجليزي الأساسي. تُراجع يدويًا عند الحاجة. تبقى أسماء الحزم والأوامر والمسارات والمعرّفات التقنية دون تغيير.

> packages/flint/core/docs/guides/development.md: [packages/flint/core/docs/guides/development.md](../../../guides/development.md)
> اللغة: العربية (ar)

هذا الدليل مخصص للمساهمين الذين يقومون بتغيير محلل Flint
العقود، أو تركيبات المطابقة.

## تثبيت والتحقق من الحزمة

من جذر المستودع، قم بتثبيت التبعيات وقم بتشغيل عمليات فحص الحزم:

```bash
pnpm install
pnpm --filter @mission-platform/flint build:check
pnpm --filter @mission-platform/flint test
```

قم بتشغيل `pnpm --filter @mission-platform/flint build` قبل النشر.
يُصدر الإصدار الحزمة الآمنة للمتصفح وملفات الإعلان ضمن `dist/`.

## إضافة تغيير اللغة

قم بتحديث القواعد النحوية والواجهة الأمامية المحددة معًا. إضافة لاعبا اساسيا مركزة ل
`src/fixtures/` واختبار الانحدار للتشخيص أو السلوك الناتج.
احتفظ بإصدار اللغة `1.0` وإصدار ABI `1.2` صريحًا ما لم يتم التغيير
مراجعة التوافق المتعمد. يجب أن تقوم تغييرات ABI بتحديث البيانات،
اللوادر ووثائق التوافق.

الحزمة آمنة للمتصفح. لا تقم بإضافة واجهات برمجة التطبيقات Node فقط إلى الواجهة العامة؛
تنتمي الأدوات الخاصة بـ Node إلى `@mission-platform/flint-cli`.

## التحف المولدة والمصدرية

مصادر `.flint` التي تم تسجيلها ضمن `src/self-hosted/fws/` هي عناصر مصدر،
جافا سكريبت غير منسوخة يدويًا. احتفظ بالمخرجات التي تم إنشاؤها في `dist/` ولا تلتزم بها
بناء الناتج المحلي. يتم الاحتفاظ بمرجع وثائق الحزمة بجانبه
الحزمة وسيتم تجديدها من خلال سير عمل استخراج الوثائق.

## فحص خط الأنابيب على مرحلتين

حدود الواجهة الأمامية الأساسية هي الرسم البياني الحتمي لبحر العقد. ال
تم تحسين الرسم البياني قبل خفضه إلى Wasm IR، حيث يتم تطبيق مُحسِّن ثانٍ
النشر الآمن للواجهة الخلفية، وإزالة التعليمات البرمجية الميتة، وتبسيط العنوان، والتبديل
خفض، والتخطيط الحتمي. اجعل كلا المرحلتين قابلتين للتدقيق: المحسن
يجب الاحتفاظ بالتقارير وسياسة الحدود المحددة في عناصر المترجم.

استخدم عمليات التحقق من حدود وقت التشغيل ما لم تحدد قاعدة إنتاج الإثبات كل منها
الوصول إلى مكان آمن. `proven-safe` و`excluded-by-profile` هما سياسة صريحة
القيم، وليس سلوك الإصدار الضمني. قطعة أثرية ذاكرة التخزين المؤقت `.sonir.json` هي
البيانات التشخيصية فقط؛ يجب على القراء التحقق من صحة المخطط والتجزئة والسياسة و
حدود قبل عرضه، ويجب عدم تنفيذ محتويات الرسم البياني أبدًا.

لفحوصات الدخان CLI:

```bash
flint check src/example.flint --bounds-checks runtime --optimizer-report --format json
flint inspect-sonir .cache/example.sonir.json --format json
```

عند تغيير التحليل، أضف الحقائق واختبارًا تشخيصيًا مستقرًا قبل التغيير
قاعدة التحسين. يجب أن يكشف تحليل التطوير عن نطاقات غير معروفة،
الاسم المستعار/حالات مدى الحياة، وتبديل التغطية، وتمرير البيانات التعريفية؛ يجب تحليل صارم
حظر طلبات سياسة الحدود غير الآمنة وانتهاكات المنطقة/الملكية.
