# تطوير خادم لغة Forge Web Script

ترجمة آلية مساعدة من المصدر الإنجليزي الأساسي. تُراجع يدويًا عند الحاجة. تبقى أسماء الحزم والأوامر والمسارات والمعرّفات التقنية دون تغيير.

> packages/forge-web-script-lsp/docs/guides/development.md: [packages/forge-web-script-lsp/docs/guides/development.md](../../../guides/development.md)
> اللغة: العربية (ar)

## التثبيت والتحقق

قم بتشغيل عمليات فحص الحزم المركزة من جذر المستودع:

```bash
pnpm install
pnpm --filter @mission-platform/forge-web-script-lsp build:check
pnpm --filter @mission-platform/forge-web-script-lsp test
```

البناء باستخدام `pnpm --filter @mission-platform/forge-web-script-lsp build`. ال
يتم إرسال النتيجة إلى `dist/`؛ الإخراج المحلي ليس قطعة أثرية المصدر.

## تغييرات البروتوكول

احتفظ بالتشخيصات ونطاقات UTF-16 والرموز والإكمال والتحويم والرمز الدلالي
السلوك المتوافق مع حزمة خدمة اللغة. إضافة انحدار البروتوكول
لاعبا أساسيا لكل طلب أو قدرة جديدة. لا يوفر LSP حاليًا
الانتقال إلى التعريف، والمراجع، وإعادة التسمية، والتنسيق، وإجراءات التعليمات البرمجية، والملفات المتقاطعة
واردات اللغة، أو النقل المستضاف في المتصفح.

الخادم يعتمد على stdio وNode فقط. ينتمي تكامل محرر المتصفح إلى
المحول المحلي لحزمة خدمة اللغة بدلاً من هذا الخادم.
