# Forge Figma repository bridge

Machineondersteunde vertaling van de canonieke Engelse bron. Handmatig nalezen indien nodig. Pakketnamen, opdrachten, paden en technische identificatoren blijven ongewijzigd.

> packages/forge-figma-bridge/docs/index.md: [packages/forge-figma-bridge/docs/index.md](../../index.md)
> Taal: Nederlands (nl)

de bridge accepts een reviewed `ForgeRepositoryExportRequest` over `POST /export` en writes de bundle into one van its explicitly configured repository roots. Configure roots met de CLI's `--root <id>=<absolute-path>` option.
