# @mission-platform/forge-web-script

Traduction assistée par machine à partir de la source anglaise canonique. À relire manuellement si besoin. Les noms de paquets, commandes, chemins et identifiants techniques restent inchangés.

> packages/compiler/forge/forge-web-script/docs/index.md: [packages/compiler/forge/forge-web-script/docs/index.md](../../index.md)
> Langue: Français (fr)

Contrats de langage Forge Web Script v1, analyseur d'amorçage et dispositifs de conformité.
Ce package possède le contrat de langue et la documentation pour les consommateurs et
contributeurs.

## Commencez ici

- [Référence du langage et de l'ABI](reference/language.md) — grammaire, types, capacités,
  diagnostics, manifestes et comportement du compilateur.
- [Guide de construction et de test](guides/development.md) — contrôles locaux, luminaires et générés
  artefacts.
- [`llms.txt`](../../../llms.txt) — API concise et notes d'utilisation pour les outils et les assistants.

Le package prend en charge la correspondance `Option`/`Result` sans exception, les exportations `iter fn`,
profils de fonctionnalités cibles explicites et débogage déterministe optimisé/non optimisé
artefacts. La version linguistique est `1.0` et la version logique ABI est `1.2`.
