# @mission-platform/forge-web-script

Forge Web Script v1 language contracts, bootstrap parser, and conformance fixtures.
This package owns the language contract and the documentation for consumers and
contributors.

## Start here

- [Language and ABI reference](reference/language.md) — grammar, types, capabilities,
  diagnostics, manifests, and compiler behavior.
- [Build and test guide](guides/development.md) — local checks, fixtures, and generated
  artifacts.
- [`llms.txt`](../llms.txt) — concise API and usage notes for tooling and assistants.

The package supports exception-free `Option`/`Result` matching, `iter fn` exports,
explicit target feature profiles, and deterministic optimized/unoptimized debug
artifacts. The language version is `1.0` and the logical ABI version is `1.2`.
