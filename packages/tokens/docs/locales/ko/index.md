# @mission-platform/tokens

정식 영어 원문을 기계 지원으로 번역한 문서입니다. 필요 시 사람이 검수하세요. 패키지 이름, 명령, 경로, 기술 식별자는 그대로 둡니다.

> packages/tokens/docs/index.md: [packages/tokens/docs/index.md](../../index.md)
> 언어: 한국어 (ko)

Mission Platform을 위한 CSS 디자인 토큰 및 SCSS 테마 정의. 이 패키지
기본, 의미, 타이포그래피, 구조 및 구성 요소 토큰을 소유합니다.
애플리케이션 및 공유 구성 요소에서 사용되는 계약입니다.

## 여기서 시작하세요

- [구성요소 토큰 참조](reference/component-tokens.md) — 인벤토리,
  DTCG 경로, 생성된 출력 및 Figma 핸드오프 계약.
- [빌드 및 테스트 가이드](guides/development.md) — 토큰 소스, 생성 및
  스타일시트를 확인합니다.
- [`README.md`](../../../README.md) — 패키지 내보내기 및 기본 설정.

`package.json`에서 패키지의 공개 `.` 또는 SCSS 하위 경로를 가져옵니다. 하지 마십시오
생성된 토큰 파일을 애플리케이션에 복사합니다.
