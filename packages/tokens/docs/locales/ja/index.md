Mission Platform の CSS デザイン トークンと SCSS テーマ定義。このパッケージ
プリミティブ、セマンティック、タイポグラフィー、構造、およびコンポーネントのトークンを所有します。
アプリケーションおよび共有コンポーネントによって消費されるコントラクト。
