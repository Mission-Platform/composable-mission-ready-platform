# @mission-platform/forms-core

תרגום בסיוע מכונה מהמקור האנגלי הקנוני. יש לבדוק ידנית בעת הצורך. שמות חבילות, פקודות, נתיבים ומזהים טכניים נשארים ללא שינוי.

> packages/ui/forms-core/docs/index.md: [packages/ui/forms-core/docs/index.md](../../index.md)
> שפה: עברית (he)

`@mission-platform/forms-core` היא ספריית ליבה אגנוסטית למסגרת המספקת את ההיגיון העסקי, הגדרות הסוג ו
מנוע אימות לטפסים ברחבי פלטפורמת המשימה. על ידי ריכוז ההיגיון הזה בחבילת TypeScript טהורה, שניהם
יישומי Vue ו-React שומרים על זוגיות מושלמת לפי בנייה.

## סקירה כללית

החבילה מתמקדת בשלושה תחומים עיקריים:

1. **הגדרת סכמת JSON**: סוגים ומבנים להגדרת סכימות טופס.
2. **נראות מותנית**: היגיון כדי לקבוע אם יש לעבד שדה על סמך ערכי טופס אחרים.
3. **אימות וברירות מחדל**: אינטגרציה עם Ajv עבור אימות סכמת JSON ויצירה אוטומטית של ברירת מחדל
   ערכים.

## מודולי מפתח

### 1. הגדרה וסוגי טפסים (`src/types.ts`)

מגדיר את החוזה המבני לטפסים:

- `SchemaFormDefinition`: הגדרת השורש. אובייקט בודד מייצג צורה חד-שלבית, בעוד מערך של אובייקטים
  מגדיר אשף רב-שלבי.
- `FormFieldSchema`: הצורה הפתורה של שדה מוכן לעיבוד.
- `FieldUiOptions`: הרחבות ל-JSON Schema כדי לספק רמזים למצגת (מרחב השמות `ui`).
- `FormValues` & `FormErrors`: הקלד מפות עבור נתוני טופס נוכחיים ושגיאות האימות המתאימות שלהם.

### 2. נראות מותנית (`src/conditions.ts`)

מספק את המנוע להעריך אם שדה צריך להיות גלוי על סמך ערכים נוכחיים:

- `evaluateCondition(condition, values)`: מעריך `FieldCondition` באמצעות קומבינטורים דמויי JSON Schema:
  - `allOf`: ולוגיקה (כל התנאים חייבים להיות נכונים).
  - `anyOf`: OR לוגיקה (לפחות תנאי אחד חייב להיות נכון).
  - `oneOf`: היגיון XOR (בדיוק תנאי אחד חייב להיות נכון).
- `isFieldVisible(field, values)`: עוזר לקבוע אם המאפיין `visibleWhen` של שדה מסוים מרוצה.

### 3. שילוב סכמת JSON (`src/json-schema.ts`)

מטפל בתרגום בין סכימות JSON גולמיות ושדות טופס הניתנים לעיבוד:

- `jsonSchemaToFields(schema)`: ממירה רקורסיבית סכמת JSON לרשימה מסודרת של `FormFieldSchema`.
- `jsonSchemaDefaults(schema)`: יוצר ערכים ראשוניים על סמך מילות המפתח `default` של הסכימה או מתאימים לסוג
  ריקים.
- `createFormValidator(schema, translate?)`: מחזירה `FormValidator` שמשתמש ב-Ajv כדי לאמת ערכי טופס. זה
  מוציא באופן אוטומטי שדות מוסתרים מאימות ותומך בהודעות שגיאה מותאמות אישית.

### 4. לוגיקה של בונה טפסים (`src/builder-types.ts`, `src/form-schema.ts`)

תומך בכלי בונה טפסים חזותי:

- **המרה**: פונקציות כמו `fieldsToSchema` ו-`schemaToFields` מאפשרות לבונה לעבור בין העבודה שלו
  ייצוג (עץ שדה) וה-`SchemaFormDefinition` הסופי.
- **פלטת שדות**: מספקת `DEFAULT_FIELD_TYPES` המגדירה את הווידג'טים הזמינים בפלטת הבנאים.

## מודל תלות

החבילה הזו היא רזה בכוונה ואגנוסטית למסגרת:

- **ללא מסגרות**: אין תלות ב-Vue או React.
- **תלות מפתח**:
  - `ajv` & `ajv-formats`: לאימות JSON Schema בעל ביצועים גבוהים.
  - `nanoid`: ליצירת מזהי שדות ייחודיים בבונה.

## צרכנים

הצרכן העיקרי הוא `@mission-platform/forms`, המשתמש בליבה הזו לכוח:

- **ForgeSchemaForm**: מעבד שדות ומאמת נתונים באמצעות כלי עזר אלה.
- **ForgeFormBuilder**: משתמש בלוגיקת ההמרה כדי לאפשר למשתמשים ליצור סכימות באופן חזותי.
