# @mission-platform/tokens

תרגום בסיוע מכונה מהמקור האנגלי הקנוני. יש לבדוק ידנית בעת הצורך. שמות חבילות, פקודות, נתיבים ומזהים טכניים נשארים ללא שינוי.

> packages/ui/tokens/docs/index.md: [packages/ui/tokens/docs/index.md](../../index.md)
> שפה: עברית (he)

אסימוני עיצוב CSS והגדרות ערכת נושא SCSS עבור Mission Platform. החבילה הזו
הבעלים של האסימון הפרימיטיבי, הסמנטי, הטיפוגרפי, המבני והרכיב
חוזים הנצרכים על ידי יישומים ורכיבים משותפים.

## התחל כאן

- [הפניה לרכיב אסימון](reference/component-tokens.md) - המלאי,
  נתיבי DTCG, פלט שנוצר וחוזה מסירת Figma.
- [מדריך בנייה ובדיקה](guides/development.md) - מקור אסימון, דור ו
  בדיקות גיליון סגנונות.
- [`README.md`](../../../README.md) - ייצוא חבילות והגדרה בסיסית.

ייבא את נתיבי המשנה הציבוריים `.` או SCSS של החבילה מ-`package.json`; לא
העתק קבצי אסימון שנוצרו לתוך יישום.
