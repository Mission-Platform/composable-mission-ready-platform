# @mission-platform/tokens

ترجمة آلية مساعدة من المصدر الإنجليزي الأساسي. تُراجع يدويًا عند الحاجة. تبقى أسماء الحزم والأوامر والمسارات والمعرّفات التقنية دون تغيير.

> packages/ui/tokens/docs/index.md: [packages/ui/tokens/docs/index.md](../../index.md)
> اللغة: العربية (ar)

رموز تصميم CSS وتعريفات سمات SCSS لـ Mission Platform. هذه الحزمة
يمتلك الرمز البدائي والدلالي والطباعة والهيكلي والمكون
العقود التي تستهلكها التطبيقات والمكونات المشتركة.

## ابدأ هنا

- [مرجع الرمز المميز للمكون](reference/component-tokens.md) - المخزون،
  مسارات DTCG، والمخرجات المتولدة، وعقد تسليم Figma.
- [دليل البناء والاختبار](guides/development.md) - مصدر الرمز المميز وتوليده و
  الشيكات ورقة الأنماط.
- [`README.md`](../../../README.md) — تصدير الحزم والإعداد الأساسي.

قم باستيراد المسارات الفرعية `.` أو SCSS العامة للحزمة من `package.json`؛ لا تفعل ذلك
نسخ ملفات الرمز المميز التي تم إنشاؤها إلى التطبيق.
