Token di progettazione CSS e definizioni di temi SCSS per Mission Platform. Questo pacchetto
possiede il token primitivo, semantico, tipografico, strutturale e componente
contratti consumati da applicazioni e componenti condivisi.

copiare i file token generati in un'applicazione.
