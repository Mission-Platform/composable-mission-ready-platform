# Forge Figma גשר המאגר

תרגום בסיוע מכונה מהמקור האנגלי הקנוני. יש לבדוק ידנית בעת הצורך. שמות חבילות, פקודות, נתיבים ומזהים טכניים נשארים ללא שינוי.

> packages/forge-figma-bridge/docs/index.md: [packages/forge-figma-bridge/docs/index.md](../../index.md)
> שפה: עברית (he)

הגשר מקבל `ForgeRepositoryExportRequest` שנבדק על פני `POST /export` וכותב את החבילה לאחד משורשי המאגר המוגדרים במפורש. הגדר שורשים עם אפשרות `--root <id>=<absolute-path>` של CLI.
