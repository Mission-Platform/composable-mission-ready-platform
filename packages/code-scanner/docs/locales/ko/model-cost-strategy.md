# 모델 및 비용 전략 — ZXING 코퍼스 전체 범위 노력

정식 영어 원문을 기계 지원으로 번역한 문서입니다. 필요 시 사람이 검수하세요. 패키지 이름, 명령, 경로, 기술 식별자는 그대로 둡니다.

> packages/code-scanner/docs/model-cost-strategy.md: [packages/code-scanner/docs/model-cost-strategy.md](../../model-cost-strategy.md)
> 언어: 한국어 (ko)

이 문서는 ZXING 블랙박스 코퍼스 작업에 요청된 **모델 계층화 매트릭스**를 캡처합니다("사용 에이전트
가장 효과적인 비용으로 이를 달성하는 최선의 방법을 결정하기 위한 다양한 모델"). 어떤 모델 계층이 가장 좋은지 기록합니다.
각 전달 단계에 적합하므로 위임 메커니즘이 있는 곳이면 어디든 작업이 가장 저렴한 경로로 전달될 수 있습니다.
가능 계층 - 단일 에이전트가 작업을 수행하는 경우 가장 많은 노력(및 가장 유능한 모델)이 수행되는 위치를 안내합니다.
지출해야합니다.

## 계층 정의

- **계층 A(최고/가장 유능한)** — 새로운 컴퓨터 비전 추론 및 사양이 많은 디코딩: 새로운 로케이터(MaxiCode
  육각형 그리드 + 불스아이, PDF417 행 클러스터링, GS1 DataBar 스택 행 어셈블리) 및 Reed–Solomon /
  오류 수정 수학(PDF417의 경우 GF(929), RSS 조합인 MaxiCode의 경우 GF(64)). 이런 부분이 가장 많아요
  미묘한 면에서 틀릴 가능성이 높으며 잘못된 첫 번째 초안에서 복구하기가 가장 어렵습니다.
- **계층 B(중간)** — ZXING 참조에서 잘 지정된 포팅: 기호 테이블, 인코더, 왕복 생성
  테스트, 하네스 로직 및 PNG 로더 일반화. 답의 모양은 알려져 있습니다. 일은 조심스러워
  전사 및 배선.
- **계층 C(저렴함/기계적)** — 대량 복사, 속성 파일, 기본 스캐폴딩, 문서 및 배선 상용구
  (형식 태그, `FORMAT_NAMES`, `ScanFormat` 조합).

## 단계 → 계층 매핑

| 무대                              | 일                                                 | 계층 |
| --------------------------------- | -------------------------------------------------- | ---- |
| 1 공급업체 코퍼스 + 로더 + 하네스 | 복사/속성(C), 로더 + 하네스 로직(B)                | C→B  |
| 2 지원 형식 읽기 속도 높이기      | 로케이터 조정 + 재시도 경로                        | A→B  |
| 3 GS1 DataBar 제품군              | 테이블/인코더(B), RSS-14 로케이터 + RS(A)          | A/B  |
| 4 PDF417                          | 테이블/인코더(B), 행 스캔 로케이터 + GF(929) EC(A) | A/B  |
| 5 맥시코드                        | 육각형 그리드 위치 + GF(64) RS (A), 테이블 (B)     | A/B  |
| 6 와이어업 + JS + 문서            | 상용구/문서 + 배선(C), wasm 재구축 + 연기(B)       | C→B  |

## 비용 원칙

Tier-C/Tier-B 공유 극대화 - 기계적 포팅(테이블, 인코더, 왕복 테스트, 배선)이
새로운 형식의 작업 — 그리고 진정으로 새로운 로케이터 세 개와 오류 수정을 위해 Tier-A 예산을 확보합니다.
약한 모델의 실수를 감지하고 수정하는 데 비용이 많이 드는 수학. 짧은 스파이크는 더 저렴한 모델을 벤치마킹할 수 있습니다.
나머지 계층을 커밋하기 전에 하나의 디코더 포트.

## 그것이 어떻게 진행되었는지

- **6단계**(이 단계)가 가장 명확한 Tier-C→B 사례: 확장
  `FORMAT_NAMES` 및 `ScanFormat` 결합은 기계식입니다(C). Wasm을 재구축하고 업로드/스트림 연기를 작성합니다.
  작은 PNG 리더가 포함된 제품군은 잘 지정된 중간 계층 작업입니다(B). 일단 네이티브가 되면 Tier-A 추론이 필요하지 않습니다.
  디코더(3~5단계)가 설치되었습니다.
- **3~5단계**는 각각 깔끔하게 분할되었습니다. ZXING 테이블/인코더 및 왕복 테스트는 Tier-B 전사였으며
  로케이터 및 Reed–Solomon(GF(929), GF(64), RSS 조합)은 Tier-A 코어였으며 매트릭스와 일치했습니다.
  위.

> 구현 중에는 맞춤형 에이전트 위임 도구를 사용할 수 없었기 때문에
> 단일 에이전트가 이 매트릭스에 따라 노력을 기울이면서 작업을 수행했습니다. 는
> 매트릭스는 여러 사람에게 위임되는 향후 재실행을 위한 지침으로 남아 있습니다.
> 모델 등급이 가능합니다.
