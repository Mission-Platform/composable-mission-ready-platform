# @mission-platform/forge-web-script

Forge Web Script v1 language contracts, bootstrap parser, and conformance fixtures

See `llms.txt` for the public API and usage examples. The package supports
exception-free `Option`/`Result` matching, `iter fn` exports, explicit target
feature profiles, and deterministic optimized/unoptimized debug artifacts.

For the language and ABI reference, see [`docs/forge-web-script.md`](../../../docs/forge-web-script.md).
