# تطوير برنامج Forge Web Script

ترجمة آلية مساعدة من المصدر الإنجليزي الأساسي. تُراجع يدويًا عند الحاجة. تبقى أسماء الحزم والأوامر والمسارات والمعرّفات التقنية دون تغيير.

> packages/forge-web-script/docs/guides/development.md: [packages/forge-web-script/docs/guides/development.md](../../../guides/development.md)
> اللغة: العربية (ar)

هذا الدليل مخصص للمساهمين الذين يقومون بتغيير المحلل اللغوي Forge Web Script، والذي تم تحديده
العقود، أو تركيبات المطابقة.

## تثبيت والتحقق من الحزمة

من جذر المستودع، قم بتثبيت التبعيات وقم بتشغيل عمليات فحص الحزم:

```bash
pnpm install
pnpm --filter @mission-platform/forge-web-script build:check
pnpm --filter @mission-platform/forge-web-script test
```

قم بتشغيل `pnpm --filter @mission-platform/forge-web-script build` قبل النشر.
يُصدر البناء الحزمة الآمنة للمتصفح وملفات الإعلان ضمن `dist/`.

## إضافة تغيير اللغة

قم بتحديث القواعد النحوية والواجهة الأمامية المحددة معًا. إضافة لاعبا اساسيا مركزة ل
`src/fixtures/` واختبار الانحدار للتشخيص أو السلوك الناتج.
احتفظ بإصدار اللغة `1.0` وإصدار ABI `1.2` صريحًا ما لم يتم التغيير
مراجعة التوافق المتعمد. يجب أن تقوم تغييرات ABI بتحديث البيانات،
اللوادر ووثائق التوافق.

الحزمة آمنة للمتصفح. لا تقم بإضافة واجهات برمجة التطبيقات Node فقط إلى الواجهة العامة؛
تنتمي الأدوات الخاصة بـ Node إلى `@mission-platform/forge-web-script-cli`.

## التحف المولدة والمصدرية

مصادر `.fws` التي تم تسجيلها ضمن `src/self-hosted/fws/` هي عناصر مصدر،
جافا سكريبت غير منسوخة يدويًا. احتفظ بالمخرجات التي تم إنشاؤها في `dist/` ولا تلتزم بها
بناء الناتج المحلي. يتم الاحتفاظ بمرجع وثائق الحزمة بجانبه
الحزمة وسيتم تجديدها من خلال سير عمل استخراج الوثائق.
