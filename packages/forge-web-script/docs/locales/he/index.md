# @mission-platform/forge-web-script

תרגום בסיוע מכונה מהמקור האנגלי הקנוני. יש לבדוק ידנית בעת הצורך. שמות חבילות, פקודות, נתיבים ומזהים טכניים נשארים ללא שינוי.

> packages/forge-web-script/docs/index.md: [packages/forge-web-script/docs/index.md](../../index.md)
> שפה: עברית (he)

Forge Web Script v1 חוזי שפה, מנתח bootstrap ותקני התאמה.
חבילה זו היא הבעלים של חוזה השפה והתיעוד לצרכנים ו
תורמים.

## התחל כאן

- [התייחסות לשפה ו-ABI](reference/language.md) - דקדוק, סוגים, יכולות,
  אבחון, גילויים והתנהגות מהדר.
- [מדריך בנייה ובדיקה](guides/development.md) - צ'קים מקומיים, מתקנים ומוצרים
  חפצים.
- [`llms.txt`](../../../llms.txt) - API תמציתי והערות שימוש עבור כלי עבודה ועוזרים.

החבילה תומכת בהתאמת `Option`/`Result` ללא חריגים, בייצוא `iter fn`,
פרופילי תכונת יעד מפורשים, וניפוי באגים דטרמיניסטי אופטימלי/לא אופטימלי
חפצים. גרסת השפה היא `1.0` וגרסת ה-ABI הלוגית היא `1.2`.
