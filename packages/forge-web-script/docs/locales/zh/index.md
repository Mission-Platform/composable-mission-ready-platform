  诊断、清单和编译器行为。
- [构建和测试指南](guides/development.md) — 本地检查、固定装置和生成的
  文物。
- [`llms.txt`](../../../llms.txt) — 工具和助手的简洁 API 和使用说明。

该软件包支持无异常 `Option`/`Result` 匹配、`iter fn` 导出、
明确的目标功能配置文件，以及确定性优化/未优化调试
文物。语言版本是 `1.0`，逻辑 ABI 版本是 `1.2`。
