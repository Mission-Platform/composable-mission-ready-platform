# @mission-platform/forms

ترجمة آلية مساعدة من المصدر الإنجليزي الأساسي. تُراجع يدويًا عند الحاجة. تبقى أسماء الحزم والأوامر والمسارات والمعرّفات التقنية دون تغيير.

> packages/forms/docs/index.md: [packages/forms/docs/index.md](../../index.md)
> اللغة: العربية (ar)

يوفر `@mission-platform/forms` مكونات تنسيق النموذج عالية المستوى التي تسمح بعرض Mission Platform
النماذج والمعالجات المعقدة بالكامل من تعريفات مخطط JSON.

مثل الحزم المشتركة الأخرى، تتبع منهج "الكتابة مرة واحدة"، حيث تقوم بتأليف المكونات في JSX المحايدة وتجميعها.
إلى مكونات Vue 3 وReact الأصلية.

تستخدم كافة الواردات محدد `@mission-platform/forms`. يتم تحديد الإطار مرة واحدة للتطبيق بأكمله
حالة التصدير `mp:<framework>` — `resolve.conditions` (راجع `defineFrameworkAppConfig` /
`frameworkResolveConditions` من `@mission-platform/vite-config`) و`customConditions` (عبر
الإعدادات المسبقة `@mission-platform/typescript-config/framework-<name>`).

## المكونات الأساسية

### `ForgeSchemaForm`

المكون الأساسي لتقديم النماذج المستندة إلى البيانات. يستغرق تعريف مخطط JSON ويقوم تلقائيًا بإنشاء ملف
عناصر واجهة المستخدم المقابلة ومنطق التحقق من الصحة.

#### الميزات الرئيسية:

- **معتمد على المخطط**: تم تكوينه بالكامل عبر مخطط JSON. كائن واحد يعرض نموذجًا من خطوة واحدة؛ مجموعة من الكائنات
  يقوم بإنشاء معالج متعدد الخطوات.
- **التحقق المتسق**: يستخدم `@mission-platform/forms-core` (Ajv) للتأكد من أن تطبيقات Vue وReact تتحقق من صحة
  نفس البيانات بشكل متماثل.
- **الرؤية المشروطة**: يدعم `ui.visibleWhen` لإظهار الحقول أو إخفائها ديناميكيًا بناءً على قيم الإدخال الأخرى.
- **البنيات المتداخلة**: تتعامل مع مجموعات الحقول المتداخلة لنماذج البيانات المعقدة.

#### الاستخدام:

**Vue** (`mp:vue` نشط):

```vue
<script setup lang="ts">
  import { SchemaForm } from '@mission-platform/forms';
  const mySchema = {/* JSON Schema */};
</script>

<template>
  <SchemaForm
    :schema="mySchema"
    @change="onValuesChange"
  />
</template>
```

**React** (`mp:react` نشط — لاحظ المحدد المطابق):

```tsx
import { SchemaForm } from '@mission-platform/forms';

const MyComponent = () => (
  <SchemaForm
    schema={mySchema}
    onChange={(values) => console.log(values)}
  />
);
```

### `ForgeFormBuilder`

أداة تأليف مرئية تسمح لغير المطورين بإنشاء مخططات النماذج دون كتابة JSON يدويًا.

#### الميزات الرئيسية:

- **Visual Canvas**: محرر نمط السحب والإفلات لترتيب الحقول وتحديد خصائصها.
- **تكوين المعالج**: علامة تبويب "الخطوات" مخصصة لإدارة التدفق متعدد الخطوات في المعالجات.
- **معاينة مباشرة**: عرض النموذج في الوقت الفعلي أثناء بنائه.
- **تصدير المخطط**: يصدر `SchemaFormDefinition` الذي يمكن حفظه في قاعدة بيانات أو استخدامه مباشرة بواسطة
  `ForgeSchemaForm`.

#### تَخطِيط:

تم تصميم المنشئ كتخطيط مكون من ثلاثة أعمدة باستخدام `ForgeVerticalLayout`:

1. **لوحة الحقول**: قائمة بالأدوات المتاحة (المدخلات، التحديدات، التواريخ، وما إلى ذلك) لإضافتها إلى النموذج.
2. **لوحة عمل المحرر**: المنطقة المركزية حيث يتم تكوين الحقول وتنظيمها.
3. **المفتش**: محرر الخصائص التفصيلية للحقل المحدد حاليًا.

## العمارة والتبعيات

لتجنب دورات التبعية مع الحفاظ على تكافؤ الإطار:

- يعتمد `@mission-platform/forms` على `@mission-platform/components` (لأدوات الإدخال الفردية مثل `ForgeInput`،
  `ForgeCheckbox`) و`@mission-platform/layouts`.
- يقوم بتفويض جميع المهام الثقيلة - التحقق من الصحة، وتحليل المخطط، والمنطق الشرطي - إلى إطار العمل الحيادي
  `@mission-platform/forms-core`.

## الأنماط

توفر الحزمة مساعدين مشتركين لإمكانية الوصول عبر:

```ts
import '@mission-platform/forms/styles';
```

يستخدم كل مكون أيضًا وحدات CSS الخاصة به والموجودة في مكان مشترك لتصميم محدد.
