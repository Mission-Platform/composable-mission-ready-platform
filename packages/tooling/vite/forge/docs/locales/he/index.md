# @mission-platform/vite-plugin-forge

תרגום בסיוע מכונה מהמקור האנגלי הקנוני. יש לבדוק ידנית בעת הצורך. שמות חבילות, פקודות, נתיבים ומזהים טכניים נשארים ללא שינוי.

> packages/tooling/vite/forge/docs/index.md: [packages/tooling/vite/forge/docs/index.md](../../index.md)
> שפה: עברית (he)

דרייבר המהדר Forge נייטרלי עבור Vite ו-tsdown. החבילה הזו
בעל ניתוח, נורמליזציה, ניתוח סמנטי, אופטימיזציה ניטרלית, מטמון,
שיגור יעד, ותזמור בנייה גנרי; פלט מסגרת ו-CMS
החבילות הן בעלות ההורדה והיצירת היעד הספציפיים שלהן.

## התחל כאן

- [התייחסות לצינור המהדר](reference/compiler.md) - חוזי שלב,
  בעלות על יעדים, שמירה במטמון, אבחון וחפצים שנוצרו.
- [מדריך בנייה ובדיקה](guides/development.md) - פיתוח מקומי ו
  בדיקות אינטגרציה.
- [`README.md`](../../../README.md) - תצורת צרכן ונציג
  Vite/tsdown דוגמאות.
- [`llms.txt`](../../../llms.txt) - חבילה תמציתית API והערות צינור.

מנהל ההתקן דורש `FrameworkOutputPlugin` מפורש; הוא אף פעם לא בוחר א
מסגרת ממחרוזת או ייבא כל חבילת יעד. מודולים שנוצרו הם
חפצי ביניים וחייבים להיות מורכבים על ידי יליד היעד שנבחר
מתאם.
